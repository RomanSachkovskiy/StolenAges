# STOLEN AGES — ЗАПУСК РАЗРАБОТКИ В CODEX CLOUD

**Статус:** исходное задание для нового GitHub-репозитория. **Цель:** выпустить **первую реально играбельную v0.1.0**, а не нарисовать макет и не ограничиться демонстрационным экраном.

**Рабочее название:** **Stolen Ages**. Русская смысловая идея — **«Вор времени»**. Называть приложение и репозиторий `stolen-ages`. Прежние названия Eraforge, Aevomarch устарели. Это рабочее название, юридическая доступность бренда отдельно не подтверждена.

## Первая команда Codex

Ты — автономный инженер реализации браузерной игры **Stolen Ages**. Работай в подключенном GitHub-репозитории `stolen-ages`; **обязательно сначала прочитай `AGENTS.md`, `docs/GAME_SPEC_V0.1.md`, `docs/RTWP_FUTURE_RESEARCH.md` полностью**. Если GitHub-репозиторий пустой, инициализируй проект. Если репозиторий ещё не создан и среда позволяет создавать репозитории GitHub — создай новый репозиторий `stolen-ages` в учётной записи пользователя с настройкой публичности по его выбору; НЕ выдавай существующий репозиторий за новый. Если среда не предоставляет создание репозитория, явно сообщи единственное необходимое действие владельца и продолжай после подключения репозитория.

**Действуй, а не пересказывай ТЗ.** Реализуй полноценную v0.1.0 по документу `docs/GAME_SPEC_V0.1.md` в несколько проверяемых коммитов: инициализация; игровой движок и модель; карта/камеры/интерфейс; экономика и захват; армии/битвы; ИИ; победа/поражение; сохранения; тесты; CI и публикация на GitHub Pages. После каждого этапа запускай доступные проверки, исправляй ошибки и фиксируй прогресс. Используй спецификацию как источник истины; разумные уточнения записывай в ADR и продолжай работу без многократных вопросов.

### Контракт результата

- `npm ci`, `npm run typecheck`, `npm run test`, `npm run build` завершаются успешно.
- `npm run dev` открывает настоящую игру: меню -> новая игра -> полностью проходимая партия -> победа или поражение -> новая игра.
- Карта занимает большую часть экрана, масштабируется, прокручивается, игрок захватывает территории, строит здания, создаёт и перемещает армии, участвует в сражениях и осадах, действует в трёх эпохах.
- Два ИИ-соперника делают осмысленные ходы; вычисление результата игры воспроизводимо по seed.
- На телефоне **портретная ориентация без разворота**, интерактивные элементы не перекрывают карту и края экрана.
- Работает на `https://<owner>.github.io/stolen-ages/`, без своего сервера; GitHub Actions запускает CI и деплой в Pages (включение Pages в настройках репо может потребовать действия владельца).
- Есть `README.md` с командами, ссылкой на игру после публикации, версией, ограничениями и инструкцией для тестирования.
- Нельзя завершать ответ статусом «сделано», пока нет доказательства (пройденные тесты + ссылка на коммит/PR + ссылка на опубликованную игру, если публикация фактически прошла).

### Порядок файлов

1. `AGENTS.md` — обязательные правила для агента.
2. `docs/GAME_SPEC_V0.1.md` — полноценное техническое задание и дизайн.
3. `docs/RTWP_FUTURE_RESEARCH.md` — дальнейшее развитие без ходов, с паузой (в v0.1 НЕ включать полноценный realtime, заложить совместимую архитектуру).

### Важное о предыдущих работах

Ранее обсуждались иллюстрации/макеты v0.4–v0.7 под именем Eraforge. **Это не означает, что v0.1 реализована.** Начинаем новую кодовую базу. Старые изображения могут служить визуальным ориентиром, но не источником игрового кода.
